🐾 Workshop 5: Animal forms and localStorage

Practice for Project 1.

Build a small animal care notebook. Practise forms, validation and saving data in the browser. Write your JavaScript in js/script.js. Open the page with Live Server.

Suomeksi

Exercise 1: Animal care form

  1. Listen for the form submit event with addEventListener(). Use event.preventDefault() to prevent the default form submission.
  2. Read the field values and use trim() to remove spaces from their ends. Show valid values in the console or on the page.
  3. Validate the form: the animal name and species must not be empty. The care note must contain 1–150 characters after trimming.
  4. Display a useful message next to each invalid field. Bonus: add the invalid CSS class to the field and remove it when the error is corrected.

Example: Nala / Elephant / Check the water bowl.

Exercise 2: Animal sponsorship calculator

Use these fictional annual fees: Elephant €10, Penguin €15, Panda €20 and Tiger €25.

  1. Read the annual fee and the number of years. Only accept positive whole years.
  2. Calculate the total: annual fee × years. Show the price with two decimal places.
  3. For more than 2 years, apply a 20% discount. For 5 years or more, also subtract €5 after the percentage discount. Show the discount below the form.

Total: not calculated yet.

Exercise 3: Saving the animal

  1. After valid submission in Exercise 1, create an object with name, species and note.
  2. Save the object under the key ws05Animal using localStorage.setItem() and JSON.stringify(). Each save replaces the previous animal.
  3. Inspect the stored value in browser developer tools: Application → Local Storage → your site address.

Exercise 4: Loading the animal

  1. When Load animal is clicked, read ws05Animal with localStorage.getItem(). If the result is null, display “No saved animal yet”.
  2. Use JSON.parse() to convert the saved text into an object. Display the animal details in savedAnimal using textContent.
  3. Reuse your loading function when the page opens. Test by saving an animal and refreshing the page.
  4. When Clear saved animal is clicked, remove only ws05Animal with removeItem() and update the displayed result.

Saved animal details will appear here.

Bonus: save several animals in an array. Restore the list after refreshing and add a delete button for each animal.

Reflection: sessionStorage and localStorage

Try sessionStorage instead, using the key ws05SessionAnimal. Save an animal, refresh the page, then close the tab and open the page again in a new tab. Compare this with localStorage. Suggest a use for each.
