Exercise 3: Practical challenge: OpenWeatherMap API

OpenWeatherMap is a well-known online provider of weather data. It offers an API that developers can use to fetch weather information. Read the documentation here.

Your task is to write a weather app that displays weather information based on the user's choices. Note: you must register for a free account to get an API key that lets you use the service.

An example REST API request could look like this: http://api.openweathermap.org/data/2.5/weather?q=Helsinki&units=metric&mode=JSON&APPID=ff64c247a136f706923d1ee0d55d71e2. Click the link to see the response.

  • First, create an app that displays raw weather data (temperature, cloud cover, and humidity) for a specified city when a button is clicked.
  • Once this works, parse the data and display it in a div.
  • Next, add an onchange event to the drop-down menu so users can choose which city's data to display.
  • Finally, add functionality to the input field so users can enter a search query, send it to the OpenWeatherMap API, and display the results in the app.
