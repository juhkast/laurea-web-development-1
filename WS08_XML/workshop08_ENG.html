Exercise 1: A practical challenge: OpenWeatherMap API

OpenWeatherMap is a well-known provider of weather data online. It offers an API that developers can use to retrieve weather information. The documentation is available here.

Your task is to write a weather app that displays weather information according to the user's preferences. Note that you need to register (for free) to get an API key that allows you to use the service.

A sample REST API request could look like this (note the mode parameter!): http://api.openweathermap.org/data/2.5/weather?q=Helsinki&units=metric&mode=xml&APPID=ff64c247a136f706923d1ee0d55d71e2. Click to see the response.

  • First, develop an app that displays raw weather data (temperature, cloudiness, humidity) for a specific city when a button is clicked.
  • Once that works, parse the data and display it in a div.
  • Next, add an onchange event to the dropdown menu so the user can choose which city's data to display from the list.
  • Finally, add functionality to the input field so the user can enter a search query, which is sent to the OpenWeatherMap API, and display the results in the app.
