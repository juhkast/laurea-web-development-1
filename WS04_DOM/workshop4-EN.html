Workshop 04 – Animals and the DOM

In this workshop, you will practise selecting HTML elements, listening for events and changing the DOM.

Select → Listen → Change the DOM

Task 1: Changing content

Add event listeners to the buttons in JavaScript. Use document.querySelector() to select the elements.

  1. The first button changes the Task 1 heading to Updated heading!
  2. The second button adds or removes the CSS class highlight from the heading. Use classList.toggle().
  3. The third button changes the animal text below. Use the textContent property.

Task 2: Creating elements with JavaScript

Create the elements for this task with JavaScript. Do not add them directly to the HTML.

  1. Select the element below with the ID animalContent.
  2. Create an h3 element containing the text Animal of the Day.
  3. Create a paragraph describing an animal of your choice.
  4. Create an img element and set its src and alt values.
  5. Attach the elements to the page with append().
  6. Add the CSS class animal-heading to the heading you created.

Add event listeners to the buttons. The first button hides the animalContent element and the second button shows it again.

Task 3: Selecting an animal

Select an animal from the drop-down menu. Change the animal's name, image and description based on the selection.

Elephant

Elephants are the world's largest land animals.

  1. Select the drop-down menu with querySelector().
  2. Add a listener for the change event.
  3. Read the user's selection from the menu's value property.
  4. Change the animal's name, image, alternative text and description based on the selection.
  5. Add a mouseenter event listener to the image. It should add the CSS class image-highlight.
  6. Add a mouseleave event listener that removes the same CSS class.

Task 4: Adding animal observations

Read the values from the form fields and add a new animal observation to the table with JavaScript.

  1. Add a listener for the form's submit event.
  2. Prevent the form's default action with event.preventDefault().
  3. Check that none of the fields are empty.
  4. Create a new tr element for the table.
  5. Create a separate td element for each value.
  6. Attach the new row to the table's tbody element.
